About This Project

International Space Station — Live

Tracks and displays the real-time orbital position of the ISS using the "Where the ISS At" API. The map updates every 5 seconds with the station's current latitude and longitude, plotted live on a Leaflet map.

API: https://api.wheretheiss.at/v1/satellites/25544
